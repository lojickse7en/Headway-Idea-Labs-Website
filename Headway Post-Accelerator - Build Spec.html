03 · Buttons

The orange gradient

Every primary button uses this exact gradient. On hover, no color change — only a soft drop-glow + 2px lift.

/* primary button fill */ background: linear-gradient(95.4deg, #FD7900 63%, #F8B170 100%); color: #fff; border-radius: 6px; padding: 13px 26px; font: 600 15px Poppins; /* hover — glow only, keep the gradient */ box-shadow: -2px 23px 89.1px 0 rgba(253,123,3,.349); transform: translateY(-2px);
Schedule Your Free Consultation ← primary CTA
Elementor tip: set this gradient once as a Global Button style (Background → Gradient, angle 95°, stops #FD7900 @63% and #F8B170 @100%), and the glow as the hover Box Shadow. Outline CTA on the dark band = transparent fill, 1.5px rgba(255,255,255,.7) border, white text.

07 · Elementor build notes

Recommended mapping

  • Global fonts: set Primary = Poppins, Text = Open Sans in Site Settings → Typography.
  • Global colors: register Navy #0E2A4D, Orange #F5841F, Teal #40A9C9, Footer #281F18, Warm #FFF9F3.
  • Sections: each block above = one Elementor Section; set the listed background and 84px top/bottom padding.
  • Cards: use a 3-col (or 2-col) inner-section / loop grid; set hover background to teal #40A9C9 with white text + 4px lift (Hover → Transform translateY -4px).
  • Pill chips & step list: Icon Box widgets; pills = full border-radius (100px), steps = numbered circle + heading + text.
  • CTA overlap: give the CTA section a negative bottom margin (~ -150px) and a higher z-index so it sinks into the footer.
  • Dropdown nav: Elementor's Mega Menu / Nav Menu with sub-items matching the live site IA.
