The workhorse grid card. Rotate the chip colour across a row (navy → teal → orange) rather than repeating one.

```jsx
<FeatureCard chip="teal" icon={<TargetIcon />} title="Founder transformation">
  The focus is not just the idea or pitch deck.
</FeatureCard>
```

Set `hoverFill` for the light-blue whole-card hover used on framework grids. Grid gap is always `var(--hw-grid-gap)` (26px).
